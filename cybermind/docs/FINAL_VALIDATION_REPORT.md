## 1. Architecture Summary

CyberMIND unites six core architectural layers into a single defensive cybersecurity platform:
1. **Frontend Presentation Layer:** Next.js 14, React 18, Tailwind CSS, Lucide icons, and React Flow visual graph canvas.
2. **Backend API & Security Core:** FastAPI ASGI application, SQLAlchemy 2.0 ORM, BCrypt password hashing, JWT Bearer tokens with RBAC (`ADMIN`, `ANALYST`, `VIEWER`), and security headers middleware.
3. **Multi-Agent Orchestrator:** LangGraph state machine coordinating 11 domain-specialized agents with an adversarial Security Reviewer enforcing structured JSON outputs.
4. **RAG Cybersecurity Brain:** Hybrid keyword + semantic retrieval engine querying database-indexed documents from OWASP, MITRE ATT&CK, NIST CSF 2.0, and CISA.
5. **Cybersecurity Digital Twin:** Graph representation modeling infrastructure nodes, trust boundaries, and protocols, with shortest-path traversal to Crown Jewels.
6. **Blockchain Evidence Provenance:** SHA-256 evidence hashing and immutable ledger anchoring for tamper-evident forensics.

## 10. Known Limitations

1. **Docker Host Dependency:** Docker is not installed on this local Windows machine; multi-container testing requires installing Docker Desktop.
2. **Paid External AI APIs:** In default standalone mode, the platform runs offline via `MockProvider`. Production deployment requires adding an `OPENAI_API_KEY` in `.env` to enable live external LLM calls.
3. **Graph Visualizer Scalability:** The current React Flow layout is optimized for up to ~100 nodes; massive enterprise topologies (>10,000 nodes) require hierarchical clustering and graph virtualization.
